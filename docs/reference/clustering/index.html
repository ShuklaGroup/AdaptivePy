    base ¶

    Clusterer ¶

    Bases: ABC

    Base interface for feature-space clustering algorithms.

    Implementations wrap scikit-learn or custom clustering methods and expose a uniform fit / predict API.

    SklearnRegularSpaceClusterer ¶

    SklearnRegularSpaceClusterer(min_dist: float, max_clusters: Optional[int] = None, random_state: Optional[int] = None)

    Bases: Clusterer

    Greedy regular-space clustering in feature space.

    This implements a distance-threshold variant commonly used in MD analysis: cluster seeds are chosen iteratively so that no two centers are closer than min_dist. All frames are then assigned to their nearest center.

    Parameters:

    Name Type Description Default
    min_dist float

    Minimum Euclidean distance between cluster centers.

    		 required
    max_clusters int or None

    Optional upper bound on the number of clusters. If None, clustering continues until no frame is farther than min_dist from existing centers.

    		 None
    random_state int or None

    Seed for shuffling frame order when selecting new centers.

    		 None

    regular_space ¶

    Regular-space clustering for molecular dynamics feature data.

    Frames are assigned to clusters such that each cluster center is at least min_dist away from all previously selected centers (in feature space). Remaining frames are assigned to the nearest center.
